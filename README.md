# jankenpo-arduino

## Apresentação

Projeto em Arduino em que se joga pedra, papel e tesoura contra o computador. Como mostra a demonstração, o circuito tem três botões e dois diodos coloridos. Os botões servem para escolher a jogada. O primeiro diodo mostra a jogada do computador, e as três cores seguem a ordem alfabética das opções em inglês. O segundo diodo mostra o resultado: uma cor para derrota, outra para vitória e outra para empate.

Como se vê no vídeo, o fluxo é simples. No começo o primeiro diodo fica apagado e o segundo fica aceso em branco, indicando que o sistema aguarda a escolha. Depois que um botão é pressionado, os dois diodos acendem em alguma das três cores, conforme a tabela do projeto.
